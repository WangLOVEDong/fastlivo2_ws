## 实录点云回归

输入为工作区已有的：
`bags/avia_camera_20261015_113203_24128.bag`。

- bag 时长约27.5秒，包含268帧 Livox 点云。
- 原版与学习版分别处理所有268帧，各检查3组抽点/盲区/线数参数。
  三组参数为 `(point_filter_num, blind, N_SCANS) = (4,2,6)、(1,0,6)、(7,5,4)`。
- 另加40组合成帧，各检查3组参数，覆盖空帧、无效 line、首点时间异常、时间跳变、
  盲区边界和重复坐标。
- 共924组帧处理，输出点总数为7,808,767。
- 对每组输出的点数、宽高和逐点 `x/y/z/intensity/curvature/normal_x/normal_y/normal_z`
  做按位摘要，原版与学习版一致：`2a4e8b1e8ec1a968`。

这项回归验证了本次重写的预处理输入输出，尤其是后续去畸变依赖的逐点时间。
它不等于对完整系统轨迹的数值对照。

## 范围限制

本轮没有启动物理雷达、相机、飞控或 RViz，也没有重新标定或修改时间同步配置。
没有宣称完整轨迹逐帧相同。PCD/COLMAP、可选视觉方法、高频预测等保留了原实现，
通过编译及函数体对照检查，本轮未对每个可选功能执行独立实机测试。

源码整理完成后，用已有 VS Code 任务回放同一份 bag，可继续观察轨迹、灰度跟踪图及彩色地图。
